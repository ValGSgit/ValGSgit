## 💼 Featured Projects

### 🦙 [Transcendence (AlpacaParty)](https://github.com/ValGSgit/AlpacaParty-ft_transcendence) — 42 Final Project

**Full-Stack Social Gaming Platform** combining an interactive 3D Alpaca Farm game with social networking features.

- 🎮 3D game environment built with Three.js
- 🔐 Secure authentication (JWT + OAuth 2.0 + 2FA)
- 💬 Real-time chat with Socket.io
- 🐳 Fully containerized with Docker, Nginx reverse proxy with SSL
- 🗄️ Dual-database architecture (SQLite/PostgreSQL), tested with Jest/Supertest

`Vue 3` `Vite` `Three.js` `Pinia` `Socket.io` `Node.js` `Express.js` `PostgreSQL 16` `Docker` `Nginx`

### 🤖 [UNIQA Conversion Coach](https://github.com/ValGSgit/ZeroOneHack-PromptCorn-Sub) — 🥈 Zero One Hackathon (2nd Place)

AI **Conversion Coach** that detects when a visitor is about to abandon an online insurance calculator and fires per-segment interventions — a trained gradient-boosting classifier blended with transparent hard rules, fully auditable.

- 📈 On held-out journeys: online conversion **~4.8% → ~17.3% (×3.6)**, trigger precision 72% / recall 86%
- 🧠 Not an LLM wrapper — real ML detection + grounded, per-segment decision logic

`Python` `scikit-learn` `Gradient Boosting` `FastAPI`

### 🌍 [Veltara](https://github.com/ValGSgit/Veltara) — Online World Game

Full-stack social platform centered around a shared Three.js planet with real-time region multiplayer, AI-powered world features, and a developer API + SDK ecosystem.

`Three.js` `TailwindCSS` `Cloudflare Workers` `Durable Objects` `Supabase + pgvector` `Stripe` `pnpm monorepo`
